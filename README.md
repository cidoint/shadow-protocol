Shadow Protocol is an original top-down stealth game built with plain canvas ES modules
(no engine, no build step). Sneak through three floors of a guarded facility: learn the
guards' patrol routes, watch their vision cones, hide in the shadows cast by crates and
pillars, keep the noise meter low, grab the intel on each floor and reach the yellow
exit unseen. Getting spotted raises the alarm — guards chase, then sweep the area, and
you get a chance to slip away and recover.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in desktop Chrome
```

WASD or arrows to move, Shift to sneak, mouse to look. Enter starts and retries.
